# ✅ Simple Checklist - Get Started in 15 Minutes

Follow this checklist to get the app running on your computer:

---

## □ Step 1: Install Python (5 min)
- [ ] Go to https://www.python.org/downloads/
- [ ] Click "Download Python"
- [ ] Run the installer
- [ ] ✅ **CHECK THE BOX: "Add Python to PATH"** (Very important!)
- [ ] Click "Install Now"

**Test it worked:**
- [ ] Open Command Prompt (Windows) or Terminal (Mac)
- [ ] Type: `python --version` and press Enter
- [ ] You should see: `Python 3.x.x`

---

## □ Step 2: Download This App (2 min)
- [ ] Get the code from your GitHub repository
- [ ] Click green "Code" button → "Download ZIP"
- [ ] Extract the ZIP to your Desktop
- [ ] You now have a folder called `franchise-data-scraper`

---

## □ Step 3: Install the App (3 min)
- [ ] Open the `franchise-data-scraper` folder
- [ ] **Windows**: Hold Shift, right-click, choose "Open PowerShell here"
- [ ] **Mac**: Right-click folder, choose "New Terminal at Folder"
- [ ] Type: `pip install -r requirements.txt` (or `pip3 install -r requirements.txt` on Mac)
- [ ] Press Enter and wait 1-2 minutes

---

## □ Step 4: Start the App (1 min)
- [ ] In the same window, type: `python app.py` (or `python3 app.py` on Mac)
- [ ] Press Enter
- [ ] Look for: `Running on http://127.0.0.1:5000`
- [ ] **Keep this window open!**

---

## □ Step 5: Open in Browser (30 seconds)
- [ ] Open Chrome, Firefox, Safari, or Edge
- [ ] Type in address bar: `localhost:5000`
- [ ] Press Enter
- [ ] **You should see the Franchise Data Scraper!** 🎉

---

## 🎯 Now You Can:

### Upload FDDs
1. Click "Upload" at the top
2. Drag a PDF onto the page
3. Wait for processing
4. See extracted data!

### Search for FDDs
1. Click "Search FDDs" at the top
2. Type "Jersey Mike's" (or any franchise)
3. Click search
4. Get links to FREE sources (Wisconsin, California, Minnesota)
5. Download FDDs from those sites

### View Data
1. Click "Dashboard"
2. See all your franchises
3. Click a card for details
4. Click "Export CSV" for Excel

### See Charts
1. Click "Visualize"
2. Interactive charts comparing franchises
3. Hover for details

---

## 🛑 When You're Done

- Press `Ctrl + C` in the Command Prompt/Terminal window
- Close the window
- Close your browser tab

---

## 🔄 To Use Again Later

1. Open Command Prompt/Terminal in the app folder
2. Type: `python app.py` (or `python3 app.py`)
3. Open browser to `localhost:5000`

---

## ❓ Problems?

**"Python not found"**
→ Reinstall Python, check "Add to PATH" box

**"No module named flask"**
→ Run: `pip install -r requirements.txt` again

**"Can't connect to localhost:5000"**
→ Make sure `python app.py` is running

**Need more help?**
→ See INSTALLATION_GUIDE.md for detailed troubleshooting

---
